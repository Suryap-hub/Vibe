# A Letter For You

A simple, browser-based letter builder with an interactive envelope experience.

## Overview

This project is a single-page HTML app (`index.html`) that lets the user:

- enter a recipient name and personal message
- optionally add a photo and timeline moments
- open a sealed envelope animation
- reveal a playful letter with a "Yes" button and a dodging "No" button
- generate a final result card with optional photo and timeline

Everything runs entirely in the browser; no server or external storage is required.

## How to Use

1. Open `index.html` in your browser.
2. Fill in the fields on the first screen.
3. Add optional photos and timeline moments, or skip the photo step.
4. Tap the envelope to open the letter.
5. Click **Yes** to reveal the final result.

## Files

- `index.html` — contains the full app markup, styles, and JavaScript.

## Notes

- No data is saved externally.
- The app uses client-side image resizing for uploads.
- The letter experience is designed for a playful proposal or greeting card interaction.
